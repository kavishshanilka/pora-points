# 🔥 පෝරා පොයින්ට්ස් (Pora Points) - University Roast & Aura Scoreboard

> **"යාලුවෙක් පෝර කෑවොත් ලකුණු අඩු කරන්න (-1)!"**  
> The ultimate web app for university squads, hostel gangs, and canteen squads to track roast marks, aura loss, and the batch leaderboard in real time!

---

## ✨ Features

- 💀 **Savage Mark Reduction**: When someone gets roasted in the circle, hit **`-1 Roast`** to deduct 1 mark! Hit **`-5 Mega Roast`** for absolute destruction.
- 🛡️ **Comeback / Aura Gain**: Made a sick comeback roast? Hit **`+1 Comeback`** to restore their marks.
- 👑 **Live Standings & Podium**:
  - **#1 පෝර රජා (King of Pora)**: The most roasted person with the lowest marks.
  - **🛡️ Aura Master**: The friend with the highest marks (roast immune).
- 🔊 **Built-in Sound Synthesizer**: Native Web Audio API sounds (*Vine Boom / Bonk*, *MLG Airhorn*, *Victory Chime*) with zero external files or lag.
- 📰 **පෝර පුවත්පත (Roast Wall of Shame)**: Log timestamps and hilarious university roast reasons (spilling canteen tea, caught bunking lectures, failing to impress crushes).
- 📸 **WhatsApp Status & Story Card Generator**: Instantly generate and download a sleek dark-neon graphic poster of the scoreboard with one click.
- 💬 **1-Click WhatsApp Group Share**: Formats clean text with emojis and rankings ready to send to your batch chat.
- 🔄 **Multi-Device Live Sync**: Share your board URL with friends so they can view and sync the same scores on their phones.
- 🇱🇰 **Bilingual**: Toggle between Sinhala slang and English anytime.
- 📱 **Mobile & PWA Ready**: Optimized for mobile screens, add to home screen with one tap.

## 🚀 How to Host on GitHub Pages

Follow these simple steps to deploy your live website:

### Step 1: Create a GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Repository name: `pora-points` (or any name you prefer).
3. Set visibility to **Public**.
4. Click **Create repository** (do not initialize with README since we already have it).

### Step 2: Push your code
Open terminal in this directory (`d:\University\extra\aura game`) and run:
```bash
git remote add origin https://github.com/kavishshanilka/pora-points.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub: `https://github.com/kavishshanilka/pora-points`.
2. Click **Settings** (⚙️) > **Pages** (in the left sidebar).
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Under **Branch**, choose **`main`** and **`/ (root)`**, then click **Save**.

Your live website link will be:  
👉 **`https://kavishshanilka.github.io/pora-points/`**

## 🎮 Game Rules
1. Every player starts with **10 Marks** (or custom starting marks).
2. Whenever a friend is roasted, clowned, or fumbles in front of the batch: **-1 Mark**.
3. For brutal incidents (e.g., getting caught by the lecturer or rejected in public): **-5 Marks**.
4. If a friend successfully delivers a comeback roast: **+1 Mark**.
5. The friend with the lowest score at the end of the day/semester is crowned **"පෝර රජා" (King of Pora)**!
